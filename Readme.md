# Security Journey

A personal learning log as I work through security labs, CTFs, and
self-built targets. This is **not** a walkthrough collection — it's a record
of what I tried, what failed, what worked, and why.

## Rules for this repo

- **No live secrets.** Passwords, flags, tokens, and keys are redacted.
  If you're doing the same labs, earn them yourself.
- **Why over what.** Commands are cheap; the reasoning is the point.
- **Wrong attempts stay in.** The failed attempts are often more instructive than the solution.
- **Nothing published that isn't mine to publish.** CTF/lab writeups are fine. Real, unpatched vulnerabilities follow responsible disclosure and
  appear here only after the vendor patches or the program allows it.
